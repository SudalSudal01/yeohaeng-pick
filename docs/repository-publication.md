# 여행픽 소스 공개

2026.10.13 사용자 요청으로 `SudalSudal01/yeohaeng-pick`을 비공개에서 공개로 전환했다. 기존 커밋과 저장소 주소를 유지했다.

- 소스: https://github.com/SudalSudal01/yeohaeng-pick
- 포트폴리오: https://sudalsudal01.github.io/backend-portfolio/
- 포트폴리오 배포 저장소: https://github.com/SudalSudal01/backend-portfolio

## 공개 전 점검 범위

전환 직전 로컬의 모든 Git 참조에서 41개 커밋·778개 고유 파일 버전을 확인했다. 로컬 환경설정의 현재 비밀 값과 대조하고, 환경설정/DB/개인키 파일 경로 및 주요 공급자 토큰·자격증명 URL·문자열 상수 패턴을 검사했다. 탐지된 8개 항목은 합성 테스트 문자열과 환경변수 조합임을 코드로 확인했다. 이 점검 범위에서 실제 비밀 값이나 제외 대상 파일을 발견하지 않았다. 주요 문서 캡처는 시연 데이터로 확인했다.

이 기록은 점검한 패턴·파일 범위의 결과다. 이후에도 `.env`, 키, 쿠키, 로컬 DB, 실사용자 자료는 기존 `.gitignore`와 개발 기준에 따라 제외한다. 사용자 요청으로 공개한 포트폴리오의 이름·연락처·사진은 공개 자료에 포함된다.

## 표시와 배포

포트폴리오 공통 콘텐츠의 여행픽 `private` 값을 `false`로 변경하고 PDF·웹 JSON·ZIP을 재생성했다. 공개 웹에서는 여행픽도 ‘코드 보기’로 표시하고, 비공개 안내를 숨긴다. PDF의 저장소 출처도 공개 링크로 연결한다.

소스 공개와 여행픽 서비스 운영 배포는 별도다. 이 변경으로 API·Oracle 또는 외부 API 키가 제공되는 것은 아니며, 실행 방법과 환경설정 예시는 프로젝트 README에 안내한다. 포트폴리오 링크는 유지되어 사람인에 등록한 주소를 다시 바꿀 필요가 없다.
