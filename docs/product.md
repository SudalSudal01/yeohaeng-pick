# 여행픽 기획 기준

저장된 여행에서는 이용 안내를 확인한 사용자가 방문일의 가능 시간과 1인당 예상 비용을 직접 정할 수 있습니다. 전체 일정 비교는 이 시간 안에서 체류를 마치는 안을 제시하고, 고정 방문·예약·조회 경로와 함께 맞출 수 없으면 이유를 표시합니다. 조건 저장이 예약 성공이나 영업 보장을 의미하지 않으며 비용은 참고 예산에만 반영합니다. [상세 범위](visit-conditions.md)

사용자와 합의한 제품 방향을 보존하는 문서입니다. 구현 완료 여부는 `status.md`가 기준입니다.

## 대상과 경험

- 국내 여행. 혼자·커플·친구·가족을 지원하는 방향이며 커플 여행을 우선 검증합니다.
- 여행 지역과 당일치기/숙박 기간, 출발지, 교통, 예산, 숙소, 취향을 버튼 중심으로 입력합니다.
- 기본 취향을 계정에 저장하고 여행별로 변경합니다.
- 비용·이동·체류·취향의 균형이 다른 세 코스를 제안합니다.
- 지역 이동과 숙소를 연결하고, 숙소 미정이면 실제 검색 후보와 외부 예약 안내를 제공합니다.
- 전체 예산을 우선 지키되 초과할 이유와 금액을 제시합니다.

## 차별화

1. 모든 주요 선택에 대안을 제시하고 선택 전 장단점과 전체 일정 영향을 비교합니다.
2. 비·휴무·매진·지연 같은 변화에 예약을 보존하는 대안을 제안합니다.
3. 초대 수락으로 취향을 합치고 함께 수정하며 충돌을 방지합니다.

현재는 방문 장소의 대안 비교, 수동 비 대응, 직접 확인한 교통 예약 시간의 보호와 방문 시간 조정안 비교를 구현합니다. 저장한 여행에서도 일반 후보와 본인이 찜한 방문 장소를 구분해 고르고, 선택한 한 곳의 현재 공급자 정보와 전체 일정 영향을 확인한 뒤 직접 적용하는 흐름으로 확장합니다. 저장 후 숙소 추가·변경도 앞뒤 이동 부담과 재확인 항목을 비교한 뒤 명시적으로 적용합니다. 날씨·휴무·매진 자동 감지와 모든 구간의 실제 경로를 반영한 전체 재최적화는 후속입니다.

## 예약과 신뢰

우리 사이트 안에서 결제를 끝낼 필요는 없습니다. 공식 예매/예약 페이지로 이동하고 결과를 수동 확인할 수 있습니다. 클릭과 예약 성공을 구분합니다. 제휴 연동이 가능한 경우에만 공급자가 확인한 성공 상태를 추가합니다. 실제 재고·가격과 추정을 구분합니다.

## 사람과 커뮤니티

- 동행 초대 수락 이후 공동 편집, 여행 단체 대화, 기본 취향 합치기
- 현재 소유자가 수락한 동행에게 소유권 이전, 이전 소유자는 동행으로 유지. 권한 확인·대기 초대 종료·별도 변경 기록
- 동행의 나가기·소유자의 참여 해제, 비공개 여행/단체 대화 권한 종료, 새 초대 수락으로 재참여. 기존 예약·지출·메시지와 공개 링크/개인 대화 정책은 별도 유지
- 현재 여행 참여자가 식당·방문 장소·출발 시각처럼 함께 정할 질문을 올리고 단일 또는 복수 후보에 투표. 선택적인 한국 현지 마감 시각, 만든 사람·현재 소유자의 마감/삭제, 후보별 합계와 내 선택만 제공. 나가기·탈퇴 시 본인 표는 지우고 질문과 남은 참여자의 결과는 공동 기록으로 보존. [상세 계약](trip-polls.md)
- 동행이 투표를 만들거나 직접 마감하면 행동한 본인을 제외한 현재 참여자에게 앱 안 알림을 제공. 알림에서 함께 준비의 투표 영역으로 이동하고 개별/전체 읽음을 지원하며, 참여 종료·탈퇴 때 받은 비공개 알림을 함께 정리. 자동 기한 종료·초대·메시지·이메일/브라우저 푸시는 후속. [알림 계약](notifications.md)
- 대표자가 비회원 동행의 조건도 입력할 수 있는 방향
- 후기·장소 추천·코스 공유·동행 모집·서비스 의견 게시판
- 작성자 글 수정·휴지통·복원과 모집 조건 변경. 댓글/개인 대화 보존, 복원 후 모집은 명시적으로 다시 열기
- 댓글 작성자의 수정·삭제와 변경 충돌 보호. 삭제 전 확인·공개 제외, 삭제한 댓글은 직접 복원하지 않음
- 사용자 간 비공개 대화, 수신 설정, 사용자 차단, 신고
- 수신 설정과 여행 참여 권한은 별도. 차단만으로 여행에서 자동 추방하지 않음
- 관리자 신고 처리와 감사 기록. 개인 대화를 일괄 열람하는 화면은 제공하지 않음

## 전체 방문 시간 조정

저장한 여행의 일정 탭에서 예약 충돌이 없어도 전체 일정 비교를 연다. 모든 날짜에 사용할 하루 시작·마감과 미조회 구간의 추가 여유를 정하고, 일찍 마치는 안과 늦게 시작하는 안의 일별 범위·방문별 전후 시각·충돌을 비교한 뒤 직접 적용한다. 기준은 이번 계산에만 사용하며 회원 기본 취향이나 여행 조건으로 저장하지 않는다.

방문 장소·날짜·순서·체류·비용과 고정 방문, 연결한 직접 확인 교통 예약, 반영한 경로 분·여유, 날짜 간 이동/숙소 출발 앵커와 숙박 조건을 보존한다. 미조회 같은 날 구간은 거리 추정+선택 여유를 사용한다. 날짜 간/숙소 연결 미반영과 일정 미연결 예약은 별도 확인 안내를 표시한다. 영업시간·좌석·객실 가능성을 보장하지 않으며 두 방향 계산의 실패가 모든 다른 순서/날짜에서도 불가능하다는 뜻은 아니다.

## 관광정보 확인

장소 탐색과 저장된 방문의 운영시간·이용정보에서 관광공사 콘텐츠를 검색한다. 이름·주소·종류를 보고 같은 장소를 직접 선택하며 지도 장소와 자동 연결하지 않는다. 이용 시간·쉬는 날·이용요금은 원문과 제공 여부, 조회 시각·공급자 수정 표기를 보여준다. 정상 미제공과 공급자 장애를 구분하고 실제 방문 가능/현재 무료/예약 가능으로 해석하지 않는다. 조회만으로 일정·예산·예약을 바꾸지 않는다. 전국 추천 후보 통합과 방문 가능 시간 제약은 후속 범위다.

## 품질 기준

앱 안 알림은 전체와 읽지 않은 항목을 버튼으로 구분하며 선택한 범위·페이지를 주소에 유지합니다. 확인할 일을 빠르게 찾고, 모두 읽은 후에도 전체 목록에서 기존 알림을 다시 볼 수 있게 합니다.

프론트와 백엔드를 분리하고 친절한 한국어 주석을 작성합니다. 포트폴리오에서 설명할 수 있도록 기획, 데이터 출처, 기술 선택, 검증 결과, 아직 검증하지 못한 사항을 기록합니다. 모바일에서 다음 행동과 현재 상태를 이해하기 쉽게 설계합니다. 서비스 이름은 **여행픽**입니다.

2026-10-12 사용자 요청에 따라 실제 프로젝트 저장소를 Oracle로 전환합니다. 기존 회원·여행 데이터를 보존하고 전용 스키마/비밀번호, SQL Developer 조회와 격리된 자동 검증을 지원합니다. H2는 기본 테스트와 간편 개발 모드로 유지합니다. [접속과 이전 기준](oracle-setup.md)

## 회원 탈퇴

마이페이지에서 소유한 여행을 먼저 넘기거나 삭제한 뒤 현재 비밀번호와 확인 체크로 탈퇴한다. 계정의 원래 로그인/프로필 정보와 작성한 글·댓글 본문은 제거하며, 공동 여행·경비·기존 대화·신고 기록은 탈퇴한 회원으로 남긴다. 개인 대화는 읽기 전용으로 종료하며 외부 예약/결제는 취소하지 않는다. 재가입은 새 계정이다. [정확한 삭제·보존 범위와 운영 과제](account-withdrawal.md)

## 2026-10-12 DB 설명 기준

새 DB 테이블·컬럼은 코드의 한국어 주석과 함께 실제 DB 코멘트에도 역할, 값/단위, 빈 값의 의미와 공개 범위를 설명한다. 기존 Oracle 도메인 테이블에도 같은 기준을 적용한다. 신고 당시 내용은 대상 한 건의 최소 정보로 보존하고 관리자 최초 처리·감사를 연결하며 운영 보존 기간은 공개 운영 전에 확정한다.
