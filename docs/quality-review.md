# 여행픽 전체 품질 재검토

2026-11-13 사용자 요청으로 전체 제품을 다시 검토한다. 과거의 대략적인 진행률 대신 구현·검증·외부 조건을 구분한다. 테스트 개수나 검토 범위를 제품 전체가 완성됐다는 의미로 사용하지 않는다.

## 검토 기준

가입·인증·취향부터 탐색·추천·저장·공동 수정·공유·예약 기록·커뮤니티·관리·탈퇴까지 연결해서 확인한다. 잘못된 입력, 중복·유실·지연, 계정/권한 변경과 외부 장애를 포함한다. 모바일 320·390px, 입력 16px·44px 실행 영역·24px 안내/실행 간격을 우선한다. 서버 권한이 최종 판단을 담당하며 합성 검증에는 실사용 DB·키·쿠키를 사용하지 않는다.

## 이어서 완료할 저장 재시도

연속 클릭은 프런트에서 막았지만 서버 저장 후 성공 응답만 유실되면 일반 여행·준비물·경비 재시도는 중복을 만들 수 있다. 메시지·공개 가져오기에 있는 요청 식별 계약을 일반 생성에도 적용한다.

UUID·입력 지문·생성 대상 ID만 비공개 영수증으로 기록한다. 같은 요청은 한 번만 저장하고 다른 본문으로 키를 재사용하면 충돌로 안내한다. 현재 권한·대상 존재를 다시 확인하며 삭제·탈퇴·참여 종료 후 대상을 되살리지 않는다. 원문과 전체 응답을 영수증에 복제하지 않는다.

## 별도로 구분하는 제품·운영 범위

| --- | --- |
| 소셜 로그인 | 미구현. 공급자 앱·리다이렉트·동의/계정 연결 정책과 실제 인증 검증 필요 |
| 지도 리뷰 | 공급자 장소 페이지 연결. 리뷰 원문 복제나 자체 리뷰 API 연결 완료로 표시하지 않음 |
| 예약·가격·좌석·객실·결제 | 외부 예약 이동 + 직접 확인한 결과/비용 기록. 공급자 성공 콜백·실시간 재고·사이트 결제 미구현 |
| 비·휴무·매진 | 사용자가 선택하는 대안과 고정 예약 보호. 자동 감지/날씨 조회 미구현 |
| 지역·숙소·최적화 | 주요 15개 지역, 지역별 숙소 1곳, 방문 순서/날짜를 보존한 시간 조정. 전국 시군구·날짜별 복수 숙소·전역 재탐색 미구현 |
| 예산 | 비용 가중치·초과 이유·미제공 비용 표시. 모든 조건에서 예산 안 코스를 보장하지 않음 |
| 메시지·알림 | 주기적 조회. WebSocket·읽음 확인·초대/메시지 푸시 미구현 |
| 실행·운영 | 임시 HTTPS 체험/별도 H2, 실사용 Oracle와 격리 QA를 구분. 상시 호스팅·보존/복구 훈련·분산 세션/한도·장애 관측은 추가 검증 필요 |
