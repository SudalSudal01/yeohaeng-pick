# 실제 교통 경로 연결

2026-10-12에 기존 앱과 REST 키로 대중교통·도보·자동차의 실제 응답을 확인했습니다. 새 공급자 계정이나 키를 추가하지 않습니다. `.env`의 `KAKAO_REST_KEY`, 카카오맵 ON 상태, 지도 SDK의 `KAKAO_JS_KEY`와 현재 웹 도메인 등록이 필요합니다. 서버 재시작 후 내 여행 → 일정 → 이동 경로 비교에서 조회합니다.

공식 문서는 [카카오맵 REST](https://developers.kakao.com/docs/ko/kakaomap/rest-api), [자동차 길찾기](https://developers.kakaomobility.com/guide/navi-api/directions), [카카오 무료 쿼터](https://developers.kakao.com/docs/ko/getting-started/quota), [카카오모빌리티 요금](https://developers.kakaomobility.com/price/)입니다. 확인 당시 카카오맵 무료 쿼터 적용 앱의 대중교통·도보는 각각 일 1,000회, 자동차는 일 10,000회였습니다. 앱별 적용 여부와 최신 정책은 개발자 콘솔에서 확인해야 합니다. 유료 활성화/결제 설정은 변경하지 않았습니다.

앱은 5분 경로 캐시와 서버 100회·회원 30회의 일일 메모리 한도를 사용합니다. 출발지 검색도 이 한도에 포함합니다. 재시작이나 여러 서버 간에는 공유되지 않으므로 운영 전 공급자 사용량 감시와 공유 제한 저장소를 추가해야 합니다. 무료 쿼터 잔량을 조회하거나 무료 사용을 보장하는 장치는 아닙니다.

대중교통은 1인 조회요금·환승·도보·단계 안내, 자동차는 기본 승용차 통행료만 표시합니다. 유류비·주차비·택시 실제 결제액은 포함하지 않습니다. 반환된 경로를 여행 날짜의 운행이나 예약 가능 좌석으로 해석하지 않습니다. 장거리/도서 지역에서 경로가 없으면 코레일·SRT·버스 공식 예매처에서 별도 확인하고 예약 결과를 직접 기록합니다.

## 날짜 간 이동과 예약 장소 연결

일정의 ‘날짜가 바뀌는 이동’에서 전날 마지막→다음 날 첫 방문을 선택해 경로를 조회합니다. 일정 영향 비교에 이동 출발 일시를 입력하면 출발 유지/다음 날 도착 유지 두 안을 볼 수 있습니다. 방문 날짜·순서·체류·활동비는 유지하고, 적용 후에는 바뀐 방문일을 보여 줍니다. 이동 자체는 자정을 넘을 수 있지만 숙소 경유·수면·휴식 시간을 자동 계산하지 않습니다. 같은 도착 방문에는 숙소 출발 구간과 날짜 간 직접 이동 중 하나의 조회 시간만 적용합니다.

예약 탭에 출발/도착 장소명을 입력하고 직접 예약 완료로 기록하면 ‘예약한 역·터미널 앞뒤 이동’이 표시됩니다. 검색 준비 → 장소 검색 → 실제 예약 위치와 일치하는 후보 선택 → 경로 조회 순서입니다. 검색 준비만으로 외부 호출을 보내지 않습니다. 앞뒤 방문은 예약 전/후의 시간상 가까운 방문이며 거리 최적화 결과는 아닙니다.

출발역까지는 방문 종료+조회 이동이 `예약 출발−탑승 전 여유`에 맞는지, 도착역에서는 `예약 도착+도착 후 여유+조회 이동`이 다음 방문 시작에 맞는지 분으로 표시합니다. 연결할 방문을 직접 바꿀 수도 있으며 선택한 방문과 예약 사이만 계산합니다. 다른 방문까지 포함한 전체 여행의 가능성을 보장하지 않습니다. 자동 운행·좌석·승차장 일치 확인은 하지 않으며 이 계산은 일정/예약을 저장하지 않습니다. 검색한 장소를 도착지로 사용할 수도 있습니다.
