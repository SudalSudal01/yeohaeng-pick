# 여행 소유권 이전

여행 상세 **함께 준비 → 함께하는 사람들 → 여행 소유권**에서 현재 소유자가 이미 초대를 수락한 다른 참여자를 선택합니다. 대상과 권한 변화·대기 초대 종료를 확인하고 체크 후 실행하면 즉시 이전됩니다. 대상자의 별도 이전 수락 요청은 없습니다. 실행 전 취소할 수 있고, 성공한 이전은 현재 소유자가 다시 넘기는 방식으로만 되돌립니다.

## 바뀌는 권한과 유지되는 기록

| 대상 | 이전 후 |
| --- | --- |
| 새 소유자 | 동행 초대·참여 해제·공개 링크 생성/종료·여행 삭제 관리 |
| 기존 소유자 | 일반 동행으로 남아 일정·예약 기록·준비물·경비·단체 대화 공동 이용. 스스로 나가기 가능, 새 소유자는 기존 소유자의 참여 해제 가능 |
| 기존 참여자·인원·취향·예산 | 그대로 유지 |
| 대기 중 초대 | 전부 REVOKED로 종료. 이전 초대 수락은 409, 새 소유자가 다시 초대해야 참여 가능 |
| 이미 수락한 초대 | 현재 참여 유지. 과거 초대 재수락은 계속 불가 |
| 일정·예약·숙소·경비·대화·방문 변경 이력 | 그대로 보존. 외부 예약·결제의 명의·계약·취소·환불과는 별개 |
| 공개 일정 링크 | 유지. 새 소유자가 종료할 수 있으며 이전 소유자는 종료 불가 |
| 열린 경로/일정 비교 | version 증가로 오래된 적용 요청 거절. 최신 여행에서 재비교 |

## API와 트랜잭션

`POST /api/trips/{id}/ownership/transfer`

```json
{"version":3,"memberId":"현재 참여자의 ID"}
```

성공은 최신 여행 상세를 반환합니다. 세션·CSRF 필수. version은 누락/null/음수 불가, memberId는 1~36자이며 자기 자신은 선택 불가(400). 비로그인 401, 현재 소유자가 아닌 참여자/외부인 403, 여행 또는 현재 대상 참여자 없음 404, 오래된 여행 버전 409입니다. 다른 계정이 존재해도 여행에 참여하지 않았거나 초대 대기 중이면 이전할 수 없습니다.

`TripOwnershipService`가 한 트랜잭션에서 여행 행 잠금 → 현재 접근/소유권/대상 참여 검사 → owner_id·version 조건부 UPDATE → 대기 초대 종료 → 변경 기록 INSERT를 처리합니다. 실패하면 전부 롤백합니다. 잠금 순서는 나가기/참여 해제·초대 발송/수락·일정·단체 대화와 동일하게 여행 행을 먼저 사용합니다.

동시 이전은 한 건만 성공하고 나중 요청은 이전 소유자가 되어 403입니다. 이전과 대상의 나가기가 겹치면 이전이 먼저일 때 나가기는 소유자 보호 409, 나가기가 먼저일 때 이전은 대상 없음 404입니다. 참여하지 않는 소유자를 만들지 않습니다. 운영 PostgreSQL 동시성 검증은 후속입니다.

## 기록과 화면 반영

V10은 `trip_ownership_history`만 추가하고 기존 V1~V9·여행·참여 행은 변경하지 않습니다. 이전/새 소유자 ID·변경 후 버전·종료된 초대 수·시각을 보관합니다. 상세의 `ownershipHistory`는 현재 참여자에게 최근 20건만 제공하며 이름은 현재 닉네임입니다. 이메일은 포함하지 않고 공개 공유에는 전체 필드를 제외합니다. 여행 삭제 시 소유권 기록도 함께 삭제하며 별도 보관 기간은 아직 정하지 않았습니다.

방문 변경 이력과 분리해 방문 복원으로 소유권이 되돌아가지 않습니다. 확인창은 열린 시점 버전과 참여자 목록을 유지하고, 15초 상세 조회/서버 오류로 변화를 감지하면 실행을 차단합니다. 최신 참여자를 확인한 뒤 대상을 다시 골라야 합니다. 최신 조회 실패가 실행을 자동 허용하지 않습니다.

자신의 성공은 서버 응답으로 즉시 역할을 반영하고, 다른 창의 변경은 다음 조회 때 반영합니다. 이전 소유자의 열린 초대/공유 창과 화면의 공유 토큰도 정리합니다. 이미 내려받은 내용을 회수하거나 비활성/오프라인 화면에 즉시 푸시하는 기능은 아닙니다.

입력 16px·안내/버튼 14px 이상·주요 실행 48px입니다. 확인 체크 아래 실행은 28px, 안내 아래 소유권 버튼은 24px 간격이며 320/390px에서 줄바꿈과 모달 내부 스크롤을 사용합니다. 혼자 참여한 여행은 빈 상태 안내만 제공하고 이전 버튼을 숨깁니다.
