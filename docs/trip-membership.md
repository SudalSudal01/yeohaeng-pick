# 여행 동행 참여 관리

여행 상세의 **함께 준비 → 함께하는 사람들**에서 현재 편집 참여자를 확인합니다. 소유자는 다른 동행의 참여를 해제하고, 동행은 스스로 여행에서 나갈 수 있습니다. 소유자는 먼저 [소유권 이전](trip-ownership.md)으로 다른 참여자에게 관리를 넘긴 뒤 동행으로 나갈 수 있습니다.

## 종료되는 권한과 남는 기록

| 대상 | 참여 종료 후 |
| --- | --- |
| 비공개 여행·일정·예약 기록·준비물·경비 | 조회·편집 불가, 내 여행 목록에서 제외 |
| 여행 단체 대화 | 조회·전송·다시 열기 불가, 방을 만든 사람도 목록에서 제외 |
| 기존 일정·예약·지출·메시지·방문 변경 이력 | 여행에 보존, 남은 참여자가 확인 |
| 여행 투표 | 나간 회원의 선택만 삭제. 질문·후보·다른 참여자의 표는 보존하며 새 초대로 돌아와도 과거 선택은 복원하지 않음 |
| 계획한 여행 인원·참고 예산·합친 취향 | 그대로 유지. 편집 계정 수와 실제 여행 인원은 별도 |
| 외부 예약·결제·정산 | 자동 취소·환불·재정산하지 않음 |
| 기존 개인 대화 | 별도 수락·차단 정책을 유지 |
| 공개 일정 링크 | 별도 공유 정책 유지. 소유자가 공유를 종료해야 폐기 |
| 이전 초대 | PENDING/ACCEPTED를 REVOKED로 전환, 재수락 불가 |
| 재참여 | 소유자의 새 초대와 해당 회원의 수락 필요 |

새 개인 대화의 ‘동행에게만 요청 받기’는 현재 함께 참여 중인 여행이 있는지 검사합니다. 다른 공동 여행이 남아 있으면 동행 자격도 남습니다. 기존에 수락한 개인 대화는 여행 참여와 별도로 유지됩니다.

## API와 동시 요청

- `POST /api/trips/{id}/leave`, 본문 `{ "version": 3 }`: 로그인한 현재 동행 본인의 참여 종료, 성공 200 빈 본문.
- `POST /api/trips/{id}/members/{member}/remove`, 같은 본문: 현재 소유자가 다른 참여자를 해제, 성공 시 최신 여행 상세.
- 세션·CSRF 필수. 권한 부족 403, 여행/대상 없음 404, 소유자 해제·오래된 버전 409, 음수 버전 400.

`TripMembershipService`의 한 트랜잭션에서 여행 행 잠금 → 현재 권한 확인 → 조건부 여행 version 증가 → 해당 회원의 `trip_poll_votes` 삭제 → 참여 행 삭제 → 이전 초대 무효화를 수행합니다. 투표 질문과 후보, 다른 참여자의 표는 건드리지 않습니다. 참여 종료 자체의 신규 스키마는 없고 V16 투표 표에서 회원 범위만 정리합니다. 예약·방문 이력 스냅샷을 만들거나 다른 공동 데이터를 삭제하지 않습니다.

`TripService.access`는 활성 트랜잭션에서 `SELECT ... FOR UPDATE`로 같은 여행의 쓰기를 직렬화합니다. 일정 변경·예약·준비물·경비·투표/재투표/마감/삭제·단체 대화 생성/전송·초대 발송/수락도 같은 여행 행을 먼저 잠급니다. 투표가 먼저 잠금을 얻으면 저장 후 참여가 종료되면서 그 회원의 표를 지우고, 해제가 먼저 완료되면 다음 투표 쓰기는 현재 참여 여부를 다시 검사해 거절합니다. 전송/편집에도 같은 원칙을 적용합니다. 이미 완료한 전송이나 시작된 읽기 응답을 취소하는 기능은 아닙니다. PostgreSQL 운영 환경의 잠금 동작은 별도 통합 검증이 필요합니다.

단체 대화 목록은 현재 `trip_members`로만 포함 여부를 결정합니다. 과거 `requester_id`가 같다는 이유로 나간 회원에게 단체 방을 보여 주지 않습니다. 개인 방에만 기존 요청자/수신자 조건을 적용합니다.

## 화면 반영

확인 창은 종료되는 접근·남는 데이터·외부 예약·재초대 조건을 설명하며 실행 전에 최신 여행 버전을 비교합니다. 다른 편집으로 버전이 바뀌면 최신 참여자를 불러온 뒤 다시 선택해야 합니다. 실행 중 중복 클릭과 닫기를 막습니다.

서버는 해제 완료 후 들어오는 요청부터 현재 권한을 검사합니다. 열린 여행 화면은 15초, 대화 내용은 5초 주기의 조회 또는 다시 조회할 때 접근 종료 안내로 바뀌며 기존 비교/예약 창을 숨깁니다. 내 여행과 대화 목록도 주기적으로 갱신합니다. 탭이 비활성화되거나 네트워크가 끊기면 화면 감지가 늦어질 수 있으며 이미 내려받은 내용을 소급 회수할 수는 없습니다. 실시간 푸시는 후속 기능입니다.

모바일은 참여자 정보와 실행 버튼을 세로 배치합니다. 안내와 실행 영역은 24px 이상 띄우고 긴 닉네임은 줄바꿈합니다. 본문 15px, 안내/버튼 14px 이상, 주요 버튼 높이 46px 이상을 유지합니다.
