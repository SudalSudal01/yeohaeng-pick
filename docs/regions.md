# 여행 지역 공통화와 15개 지역 검색

2026-10-13 포트폴리오 기준 필수 기능 마감 범위입니다. 모든 시군구를 지원한다고 표시하지 않고, 아래 주요 지역만 현재 검색 대상으로 제공합니다.

## 지원 지역

서울·부산·제주·강릉·인천·대구·대전·광주·울산·수원·경주·전주·여수·속초·춘천.

- 광주는 기존 광주권의 **동구·서구·남구·북구·광산구**이며 경기도 광주시나 전남 전체를 포함하지 않습니다.
- 일반 도시는 해당 시만 포함하고 상위 도 전체로 확대하지 않습니다.
- 제주는 기존 계약대로 제주특별자치도 전체입니다.
- 복수 지역은 기존과 같이 한 여행 최대 5곳, 지역 수 이하가 아닌 여행 일수가 필요합니다. 전체 기간은 최대 14일입니다.
- 로컬 예시 모드에서는 예시가 있는 기존 서울·부산·제주·강릉 4곳만 선택지에 제공합니다. 새 지역에 임의 예시 장소를 만들지 않았습니다.

## 서버 계약

`TravelRegions`가 지원 이름·공식 시도 별칭·시 경계를 함께 관리합니다. `/api/config`의 `regions`가 현재 검색 모드에서 선택할 수 있는 이름 목록을 제공합니다.

Kakao 검색어에도 상위 행정구역을 넣어 동명 지역의 결과가 상위 15건을 차지하는 일을 줄입니다. 응답 주소의 첫 시도와 시 단어를 다시 검증하므로 상호·도로명에 지역 이름이 포함돼도 통과하지 않습니다. 업종 분류도 기존과 같이 공급자의 업종 경로를 기준으로 합니다.

실제 공급자는 광주·전남의 주소를 `전남광주통합특별시`로 반환하고 있습니다. [행정안전부의 2026.7.1 변경 안내](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=127039)와 [국토교통부 법정동 현행화 자료](https://www.data.go.kr/data/15063424/fileData.do)를 확인해 기존/현재 시도 이름을 함께 처리합니다. 여수는 같은 상위 명칭 아래에서도 `여수시`만 통과하고, 광주는 위 5개 구만 통과합니다. 광주 키워드가 전남 전체를 검색하는 경우를 줄이려고 [Kakao의 검색 사각형](https://developers.kakao.com/docs/en/local/dev-guide)으로 후보를 좁힌 뒤 실제 구 주소를 다시 검증합니다. 사각형 자체를 행정 경계 판정이나 사용자의 위치로 사용하지 않습니다.

TourAPI는 코드 숫자를 하드코딩하지 않습니다. 현재 `ldongCode2`의 공식 시도 명칭을 찾고, 일반 도시는 시군구 목록에서 해당 시의 코드를 찾습니다. 없는 코드나 외부 장애를 다른 지역·예시로 대체하지 않습니다. 법정동 검색 계약은 [공공데이터포털 공식 서비스](https://www.data.go.kr/data/15101578/openapi.do)를 기준으로 확인했습니다.

`Planner.validate`는 추천·저장·공개 가져오기에 같은 지원 지역 검사를 적용합니다. 직접 조작한 지역은 외부 호출 전에 400으로 거절합니다. 기존 일정/숙소/지역 저장 의미와 Flyway 구조는 바꾸지 않았습니다.

## 화면

- 홈의 지역 선택, 탐색과 여행 만들기의 지역 버튼은 같은 서버 목록을 사용합니다.
- `RegionChoices`는 로딩·오류·다시 시도와 현재 선택의 `aria-pressed`를 제공합니다.
- 계획 화면은 최대 5곳을 넘기는 선택을 안내하며 선택 숫자로 방문 순서를 표시합니다.
- 잘못된 주소의 지역은 안내하고 다음 단계를 막습니다. 지원 지역을 다시 선택하면 잘못된 지역을 제거합니다.
- 찜은 개인 목록에 실제로 들어 있는 지역으로 필터를 만들어 예시 모드나 지원 목록 변경 후에도 보관한 장소를 찾습니다.

## 검증과 한계

합성 HTTP 공급자로 15개 지역 주소 분류, 인접 도시 제외, 지원하지 않는 요청, 예시 모드 4곳, 경주→전주 추천 3코스와 저장 재검사를 확인했습니다. 관광공사의 새 시/광역시 코드 선택과 잘못된 코드 실패도 별도 공급자 테스트로 확인했습니다. 실제 Kakao 지역별 검색과 320px·390px UI를 확인했습니다.

검색은 공급자 상위 결과와 분류/주소 재검사에 제한됩니다. 결과가 적거나 빈 상태일 수 있고, 지역의 모든 장소·행사·숙소 재고를 수집한 것이 아닙니다. 요금·영업·공실·예약 성공은 계속 별도 확인 대상입니다.
