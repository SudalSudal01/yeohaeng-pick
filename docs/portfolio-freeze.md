# 포트폴리오 기준 기능 동결

2026-10-13 사용자 요청: 전체 서비스가 완성될 때까지 새 기능을 늘리기보다, 현재 필수 기능과 테스트를 마친 뒤 회사 지원용 파일·웹 포트폴리오를 만든다.

## 이번 마감 범위

- 진행 중이던 지역 확대를 공통 지원 목록·검색·주소 검증·관광공사 조회·홈/탐색/계획/찜까지 연결한다.
- 기존 추천·저장·권한·공동 편집·예약 보호 흐름의 회귀 테스트와 해당 지역 확대 Oracle HTTP 검증을 마친다.
- 모바일 320px·390px에서 선택과 안내·버튼·가로 넘침을 확인한다.
- 구현·한계를 `status.md`, `verification.md`, `regions.md`에 기록하고 기능 단위 Git에 반영한다.
- 이후 자동 만료/메시지 알림·소셜 로그인·추가 여행 지역 같은 신규 개발은 보류한다.

## 포트폴리오

이름 김명현, 백엔드 지원. 프로젝트 비중은 제때약 → 여행픽 → 5ASIS이며 팀 기여도는 사용자가 확인한 담당만 표기한다. 지원용 8쪽 PDF와 정적 웹은 `portfolio/`의 같은 콘텐츠 원본을 사용한다. 역할·기술·문제 해결·검증 근거·한계를 담고, 확인하지 않은 경력·학력·수치나 배포 완료를 넣지 않는다.

제때약과 5ASIS 전체 서비스를 이번 요청으로 수정하거나 재배포하지 않는다. 원격 저장소와 팀 결과보고서를 읽어 담당 기능 설명의 근거로 사용한다. 팀 과거 테스트 기록과 여행픽 최신 실행 결과를 구분한다.

정적 포트폴리오 배포는 여행픽 API/Oracle 서비스 배포와 별도다. 이번 로컬 미리보기와 배포용 파일 제작이 인터넷 공개를 의미하지 않는다. 공개 저장소·호스팅 연결은 공개 범위를 확인한 뒤 진행한다.
