## 권장 후속 순서

사용자 요청에 따라 새 기능보다 기존 UI의 가독성을 우선합니다. 공통 기준은 `AGENTS.md`와 스타일 토큰에 기록했으며 이후 화면에도 같은 기준을 적용합니다.

1. 실제 검색 결과의 여행 분류·지역 범위를 정교하게 하고 다양한 기간·취향의 추천 품질과 모바일 UX를 확인한다. 연결한 SMTP의 비밀번호 재설정 흐름도 확인한다.
2. 직접 확인한 교통 예약의 시간 보호와 조회 구간 시간 반영은 구현했다. 적용한 구간은 조회 시간, 나머지는 거리 추정을 사용한다. 다음은 날짜 간 이동·역/터미널 연결과 전체 일정 최적화를 보강한다. 지역 간 항공·선박과 날짜별 운행/좌석은 별도 공급자 검토가 필요하다.
3. TourAPI로 지역·행사·체험 분류를 확장하고 영업시간/입장료의 확인 여부를 구조화한다.
4. 숙소별 날짜·객실·인원 조건, 숙소 변경 비교, 도착/출발 예약 시간의 고정 제약을 엔진에 추가한다.
5. 소셜 로그인, 회원 탈퇴/권한 회수, 콘텐츠 편집·삭제, 조회 페이지네이션, 신고 운영 정책을 완료한다.
6. PostgreSQL 통합 테스트, 운영 환경의 메일 수신·발송 한도, HTTPS·백업·관측·분산 세션과 한도를 검증한다.
7. 제휴가 확보된 공급자에 한해 예약 콜백/재고/가격을 연동한다. 이 시점 전에는 PARTNER_CONFIRMED를 사용자 입력으로 허용하지 않는다.

무료 우선 원칙은 실제 공급자의 할당량과 운영비를 확인하며 지킵니다. 현재 메모리 호출 제한은 단일 프로세스용이며 서버 재시작/다중 인스턴스에 걸친 과금 방지 장치가 아닙니다.
